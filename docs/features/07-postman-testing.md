# 07 Testing the APIs with Postman

1. Start the stack: `docker compose up --build -d` (synthetic demo data loads on first start).
2. Postman -> Import -> `postman/Peak-HRMS-Core.postman_collection.json` and `postman/local.postman_environment.json`.
3. Choose the environment "Peak HRMS local (synthetic)" (top right).
4. Run the whole collection (Run collection) - folders in order:
   00 sign-in · 01 look up demo records · 02 Company Setup CRUD for all 26 entities · 03 the eleven rules · 04 onboarding · 05 users.
5. Request "03 > 9 Excel import" needs the file `postman/samples/departments-import.xlsx`: if Postman cannot find it, pick it in the Body tab.

Every request has tests (expected status code and key values), so the run shows pass/fail per call. The collection can be run again:
each run uses new codes. CI runs the same collection with newman against a fresh Postgres database.
The collection is generated by `scripts/make_postman.py`; change the script and run it again rather than editing the JSON.
